### v3.0.0 <br>

### 🪟 Mini Widget Mode

When you switch to **Mini Widget mode**, the window shrinks into a compact always-on-top widget, perfect for keeping focus while working on other tasks.

Hovering over the mini widget reveals a **control bar** with the following actions:

- ⏸ **Pause / Resume** — Instantly pause or resume your current session without switching back to the full window.
- ⏹ **Stop / Exit Mini Mode** — Exit the mini widget and return to the normal window view.

The bar auto-hides when not in use, keeping the widget clean and unobtrusive. The **status indicator** (a colored dot + session info) stays visible at all times so you always know what mode you're in.

### 📊 Stats Page Improvements

- **Week View** — Now shows the **last 7 days from today** instead of a fixed calendar week.
- **Month View** — Trend chart split into **two rows** for wider, clearer bars.
- **Today's Marker** — Red circle highlights the current day in the trend.
- **Adaptive Format** — Bar values show full precision in Week/Day (`3.57h`) and compact format in Month (`3.5h`).
- **Dynamic Labels** — The mini card switches between **"This Week"** and **"This Month"** based on the selected tab.
- **Clean Transitions** — No leftover styles when switching between Day, Week, and Month.
- **Better Readability** — Larger day numbers, clearer value labels, wider bars.
